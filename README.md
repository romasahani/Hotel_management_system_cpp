# Hotel Management System

A console-based **Hotel Management System** developed in **C++** to manage hotel operations such as room booking, customer records, check-in/check-out, and billing using file handling.

## 📖 Overview

The Hotel Management System is a C++ console application designed to simplify basic hotel operations. It allows hotel staff to manage customer information, room bookings, and hotel records through a menu-driven interface.

This project was developed as part of my Computer Engineering coursework to strengthen my understanding of Object-Oriented Programming (OOP), file handling, and data management in C++.

---

## ✨ Features

- Customer registration
- Room booking and allocation
- Check-in and check-out management
- Customer record management
- Billing system
- File-based data storage
- Menu-driven console interface

## 🚀 Getting Started

### Prerequisites

- GCC / G++
- Code::Blocks
- Visual Studio
- Visual Studio Code
- Dev-C++

### Compile

```bash
g++ Hotel_management_system.cpp -o hotel_management
```

### Run

**Windows**

```bash
hotel_management.exe
```

**Linux/macOS**

```bash
./hotel_management
```
